# Anagen

Program dla gabinetów trychologicznych: karty klientów, wizyty, zdjęcia z kamery trichoskopowej, raporty i porównania.

**[Pobierz instalator dla Windows](https://github.com/kostek895/anagen-releases/releases/latest/download/Anagen-win-Setup.exe)** (Windows 10/11, 64-bit)

Zainstalowany program sam pobiera aktualizacje z tego repozytorium.
